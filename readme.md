# 🦟 MosquitOFF

Um mini jogo de navegador onde você deve clicar nos mosquitos que aparecem aleatoriamente na tela antes que desapareçam. Perdeu 3? Game over! Ganhou? Parabéns, exterminador!
## ▶️ Como rodar o projeto

1. Baixe ou clone este repositório:
   ```bash
   git clone https://github.com/eduardar0/game-mosquito-js.git

## 🚀 Como jogar

1. Acesse o arquivo `index.html` e selecione o nível de dificuldade:
   - Normal (mosquitos a cada 1,5s)
   - Difícil (mosquitos a cada 1s)
   - Chuck Norris (mosquitos a cada 0,75s)

2. Clique em "Iniciar Jogo".
3. Use o cursor (raquete mata-mosquito 🪰) para clicar nos mosquitos.
4. Não perca 3 mosquitos!

## 🧠 Funcionalidades

- Três níveis de dificuldade
- Sistema de vidas
- Cronômetro regressivo
- Estética simples com tema tropical
- Responsivo para diferentes tamanhos de tela
